# Моя дорожка — Android project

Локальный журнал тренировок на Android. Интернет и регистрация не требуются.

## Возможности
- Запись тренировки текущим моментом: дата и время ставятся автоматически при сохранении.
- Скорость, длительность, расстояние и ориентировочные калории.
- Профиль: вес, рост, возраст, пол.
- История тренировок, редактирование и удаление.
- Скрытое добавление прошлой тренировки: удерживайте заголовок «МОЯ ДОРОЖКА».
- Все записи выглядят одинаково, без пометок о ручном добавлении.
- Данные хранятся локально в SharedPreferences приложения.

## Сборка APK
1. Установите Android Studio (актуальную стабильную версию) и Android SDK Platform 35.
2. Откройте папку `TreadmillJournal` в Android Studio.
3. Дождитесь Gradle Sync.
4. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Требуется JDK 17. Минимальная версия Android — 8.0 (API 26).

## Оценка калорий
Используются ориентировочные MET-значения по диапазону скорости, весу и длительности. Это оценка, не измерение. Рост, возраст и пол сохраняются в профиле, но в выбранной MET-формуле напрямую не участвуют: для оценки энергозатрат ходьбы ключевыми являются масса тела, интенсивность и время.
